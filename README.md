# weston — منصة الذكاء الاصطناعي بالعربي

مسار كامل **مجاني 100%** لتعلّم الذكاء الاصطناعي من الصفر إلى الاحتراف والعمل — بنظام منصات التعلّم الكبيرة: **مسارات تخصص** (تدخل بيها جوه الـ AI نفسه) و**مسارات تطبيق** (تستخدم الـ AI في شغلك).

## 🌐 اللينك المباشر (على الإنترنت)

```
https://nabhanvideoeditor.github.io/weston/
```

المنصة منشورة على GitHub Pages — افتح اللينك من أي جهاز، من غير أي تثبيت.

## التشغيل محلياً (اختياري)

**الأسهل:** اضغط مرتين على الملف **`ابدأ-المنصة.bat`** — هيشغّل سيرفر محلي ويفتح المنصة في المتصفح تلقائياً.

**أو يدوياً:** افتح `index.html` — المنصة تعمل بدون إنترنت (الفونت محلي)، بس **الفيديوهات المدمجة محتاجة سيرفر** عشان يوتيوب بيمنع التضمين من `file://` (خطأ 153):

```bash
cd nabhan-ai-academy
python -m http.server 8765
# ثم افتح http://localhost:8765
```

لو فتحتها كملف وهتلاقي الفيديو مبيعملش، هتظهر لك رسالة تحذير في صفحة الكورس تدلك على الحل. وكل فيديو فيه كمان رابط **«▶ شغّل على يوتيوب»** احتياطي.

## نظام المنصة

| الصفحة | الوصف |
|---|---|
| **الرئيسية** | ترحيب + إحصائيات + **قسم تحفيز** (سلسلة مذاكرة، اقتباس يومي، زاد اليوم) + مميزات + مسارات وكورسات مقترحة |
| **خطتي** | خطة **14 شهر / 56 أسبوع** من الصفر للاحتراف والشغل — كل أسبوع له هدف ومهمة وعادة، مع زاد اليوم (آيات وأدعية) |
| **المسارات** | 13 مسار: تخصص (رياضيات، أساسيات، Python، ML، DL، GenAI، MLOps، متقدم) وتطبيق (هندسة أوامر، كلود كود، أوتوميشن، أعمال، تصميم) |
| **الكورسات** | 62 كورس مجاني بمصادر عالمية + **10 كورسات بمحتوى فيديو مدمج جوه المنصة** 🎬 |
| **صفحة كورس** | **شغّل المحتوى هنا** (فيديوهات يوتيوب مدمجة) + الدروس والمدة والمستوى والشهادة |
| **تقدّمي** | حلقة نسبة + تقدم كل مسار، حفظ تلقائي على جهازك |
| **الشهادات** | 9 شهادات إتمام مجانية معتمدة |
| **الأدوات** | 12 أداة مجانية |
| **الأسئلة الشائعة** | إجابات + مصادر إضافية |

## التصميم

- هوية **AI**: داكن فحمي + نيلي `#6d7cff` + سماوي `#38bdf8`
- **شبكة عصبية حية** في الواجهة + توهج نيون
- فونت **Alexandria** (Google Fonts)
- عربي RTL بالكامل، متجاوب مع الموبايل
- نظام تحفيز: سلسلة أيام متتالية، اقتباس يومي، رسائل تشجيع حية 🎉

## إضافة فيديو مدمج لكورس

في `assets/js/videos.js`:

```js
"c-id-الكورس": [
  { type: "playlist", id: "PL…", t: "اسم القائمة" },
  { type: "video",    id: "VIDEO_ID", t: "اسم الفيديو" },
],
```

- `type: "playlist"` → `https://www.youtube.com/embed/videoseries?list=…`
- `type: "video"` → `https://www.youtube.com/embed/VIDEO_ID`

## تعديل المحتوى
